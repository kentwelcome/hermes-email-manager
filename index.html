Hermes Email Manager helps Kent Huang review Gmail, identify follow-ups, and prepare reply drafts with AI assistance.

This is a personal-use tool, not a public email service. This website explains the project and its data practices; it does not provide sign-in or access to a mailbox.

What the tool is for

The workflow supports inbox triage, message classification, summaries, follow-up tracking, and drafting replies. Gmail access is authorized separately through Google OAuth.

How information is handled

Mail information needed for a requested task may be processed by the configured AI services. Summaries and task results may be delivered through configured notification services, such as Slack. These integrations run separately from this public website.

This site contains no mailbox data, OAuth credentials, embedded analytics, or sign-in forms. Hermes Email Manager is an independent project and is not affiliated with or endorsed by Google.
